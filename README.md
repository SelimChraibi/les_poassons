# Les poassons

Un aquarium où tu dessines tes propres poissons, puis tu les regardes vivre : nourris-les, décore leur paysage, change la météo et le moment de la journée.

**Jouer : https://selimchraibi.github.io/les_poassons/**

Tout le jeu tient dans `index.html`. Tes dessins et ta partie restent dans ton navigateur.
